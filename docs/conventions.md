# 仓库约定

## 分层

| 层 | 位置 | 职责 | 不允许做的事 |
| --- | --- | --- | --- |
| 网络层 | `core/` | 签名、限速、重试、登录态、错误分类 | 不解析业务字段 |
| 采集层 | `collectors/` | 调接口、解析成结构化数据 | 不写文件、不碰第三方存储 |
| 导出层 | `exporters/` | 落盘、写飞书表格 | 不发网络请求 |
| 入口层 | `cli.py` | 参数解析、编排 | 不写业务逻辑 |

## 命名

- 输出文件：`<分组>__<BV号>.json/.srt/.txt`
- 飞书子表：`<标题前 24 字>-<BV号>`，去掉 `\ / ? * [ ] :`
- 分区子表：`>>>供给侧` / `>>>需求侧`
- 汇总子表：`汇总-视频清单`
- 评论子表：`评论-供给侧` / `评论-需求侧`

## 数据口径

- 字数：不计空白与标点，与已有语料统计一致；
- 覆盖率：最后一段结束时间 ÷ 视频时长，用于判断字幕完整性；
- 来源：`AI字幕` / `音频转写`，转写稿必须在文档里单独说明质量差异；
- 评论时间：接口返回的 Unix 时间戳，导出时保留原值。

## 版本

采集结果必须记录采集日期（飞书子表里的「采集日期」字段），因为播放量、评论数会随时间变化。
