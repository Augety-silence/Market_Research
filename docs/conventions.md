# 仓库约定

## 分层

| 层 | 位置 | 职责 | 不允许做的事 |
| --- | --- | --- | --- |
| 网络层 | `core/` | 签名、限速、重试、登录态、错误分类 | 不解析业务字段 |
| 采集层 | `collectors/` | 调接口、解析成结构化数据 | 不写文件、不碰第三方存储 |
| 导出层 | `exporters/` | 落盘、写飞书表格 | 不发网络请求 |
| 入口层 | `cli.py` | 参数解析、编排 | 不写业务逻辑 |

## 命名

- 输出文件：`<分组>__<BV号>.json/.srt/.txt`
- 飞书子表：`<标题前 24 字>-<BV号>`，去掉 `\ / ? * [ ] :`
- 分区子表：`>>>供给侧` / `>>>需求侧`
- 汇总子表：`汇总-视频清单`
- 评论子表：`评论-供给侧` / `评论-需求侧`
- 评论子表第一列组固定为：`BV号 / 标题 / 药物 / 分组 / 评论ID / 根评论ID / 用户 / 时间 / 点赞 / 回复数 / 是否楼中楼 / 正文`

## 数据口径

- 字数：不计空白与标点，与已有语料统计一致；
- 覆盖率：最后一段结束时间 ÷ 视频时长，用于判断字幕完整性；
- 来源：`AI字幕` / `音频转写`，转写稿必须在文档里单独说明质量差异；
- 评论时间：接口返回的 Unix 时间戳，导出时保留原值。
- 药物：按视频讨论的目标成分/药品标注（`司美格鲁肽` / `左旋肉碱` / `奥利司他`），
  多药物对比类视频写成 `多药物：A/B/C`，不要留空；判定依据是字幕与评论里的实际提及，
  不只看标题（ASR 常把「奥利司他」写成奥利斯他/奥利斯塔）。

## 版本

采集结果必须记录采集日期（飞书子表里的「采集日期」字段），因为播放量、评论数会随时间变化。


## 季度搜索扩展

季度模块沿用网络/采集/导出/入口分层；浏览器和飞书公开API请求放在 `core/`，校验放在 `collectors/`，断点及写出放在 `exporters/`。季度飞书导出通过网络适配器请求，不直接操作浏览器。依赖限定在可选 `quarter` extra，基础命令不能在导入时加载第三方库。

季度快照只保存公开元信息，不包含Cookie、访问令牌、浏览器profile或个人飞书资源ID。季度关键词匹配不代替供需标注，播放量为采集时累计值，详细口径见 [季度采集](features/quarter-search.md)。
