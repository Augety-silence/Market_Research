# 研究框架：减重药内容的两类供给

## 研究对象

同一议题下的两类内容供给，用同一套语料口径对比：

| 类型 | 主体 | 典型诉求 |
| --- | --- | --- |
| 供给侧推广 | 品牌方、营养品商家、带货达人 | 把产品卖点包装成“科普”，引导购买 |
| 需求侧科普 | 医生、科普博主、测评号 | 解释机制、风险与适用边界 |

## 语料口径

每条视频为一个分析单元，采集：元信息（UP 主、播放、评论数、时长）+ 正文全文（字幕或转写）+ 评论区。

## 可分析的三个层面

1. **话术结构**：痛点唤起 → 机制解释 → 证据引用 → 风险弱化 → 转化引导。统计各环节出现率与顺序。
2. **证据等级**：个人体验 / 用户见证 / 引用研究 / 专家身份，四类证据在不同主体间的分布。
3. **认知边界**：处方药适应症、超说明书使用、副作用与停药反弹，科普侧与推广侧的覆盖差异。

## 采集注意事项

- 播放量与评论数是页面计数，随时间变化，分析时需记录采集日期；
- AI 字幕缺少标点，需要规则还原，长句可能仍需人工校对；
- 无字幕视频用音频转写补齐时，要在方法部分单独说明来源差异。
