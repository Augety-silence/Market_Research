# 飞书表格模块

## 工作簿约定

一个工作簿对应一个研究课题，按下面的结构组织：

| 子表 | 内容 |
| --- | --- |
| `汇总-视频清单` | 所有视频一行一条：分组、BV 号、标题、UP 主、时长、播放、评论数、段数、字数、覆盖率、来源 |
| `>>>供给侧` | 分区标记，其后紧跟该组视频子表 |
| `<标题>-<BV号>` | 单个视频：顶部信息块（标题/BV/UP 主/时长/播放/评论/段数/字数/覆盖率/来源/采集日期）+ 字幕逐段表（序号/开始/结束/正文） |
| `>>>需求侧` | 同上，需求侧分组 |
| `评论-供给侧` / `评论-需求侧` | 评论一行一条，带 BV 号与标题 |

子表顺序按「汇总 → 供给侧 → 需求侧」排列，工作簿里原有的示例子表会保留在末尾，不会被删除或改名。

## 命令

```bash
python3 -m bili_research push-feishu --url "<表格链接>" --corpus corpus
```

可重复执行：已存在的子表会先清空内容再写入，不会重复建表；新增视频会自动补建子表。

## 实现说明

- 通过 `lark-cli sheets` 写入，需要本机已安装并完成登录；
- 数值列（时长、播放、段数、字数、覆盖率）按数字写入，保持可排序、可计算；
- 写入前自动把子表行数扩展到所需规模（最长的一条视频有 1245 段）；
- 写入后可用 `lark-cli sheets +csv-get` 回读抽样校验。

## 在其他 agent 上使用

如果目标环境没有 `lark-cli`，跳过这一步即可：采集结果仍会完整落在本地 `corpus/`（JSON + SRT + TXT + index.csv），可以换成任何表格/数据库写入。
